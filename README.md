# PushUp Tracker — Telegram-бот для отжиманий

Telegram-бот для ежедневного челленджа по отжиманиям.

Бот принимает видеокружочки (`video_note`), автоматически подсчитывает отжимания с помощью MediaPipe и сохраняет результаты в SQLite.

Если распознать отжимания не удалось, бот запрашивает количество вручную. Такие результаты отмечаются ✍️ и могут быть перепроверены.

Каждый день в **00:00** бот публикует отчёт о выполнении дневной нормы без рейтингов и соревнований. При невыполнении нормы на следующие сутки назначается штрафная норма.

Дополнительно реализованы:

- Белый список разрешённых Telegram-групп.
- Автоматический выход из неразрешённых групп.
- Белый список пользователей для личных сообщений.
- Управление доступом через команды владельца.
- Debug-анализ кружочков в личке без записи в статистику.
- Команда `/rules` с правилами из отдельного файла `rules.txt`.

## Сервер

Виртуальная машина (VPS):

- **OS:** Ubuntu 24.04 LTS
- **CPU:** 2 vCPU
- **RAM:** 2 GB
- **SSD:** 40 GB
- **Swap:** 1 GB

Приложение запускается через Docker Compose.

## Установка и запуск

### 1. Установка Docker

```bash
sudo apt update
sudo apt install -y docker.io docker-compose-v2 git
sudo systemctl enable --now docker
```

### 2. Клонирование проекта

```bash
git clone <REPOSITORY_URL>
cd push-up-tracker
```

### 3. Настройка окружения

```bash
cp .env.example .env
nano .env
```

Основные переменные:

```dotenv
BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN

REPORT_TIMEZONE=Europe/Moscow
DAILY_TARGET=100
CASH_FINE=1000000

OWNER_ID=123456789

ALLOWED_CHAT_IDS=-1001234567890
ALLOWED_USER_IDS=111111111,222222222
```

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | Токен Telegram-бота |
| `REPORT_TIMEZONE` | Часовой пояс ежедневного отчёта |
| `DAILY_TARGET` | Базовая дневная норма |
| `CASH_FINE` | Штраф для вывода в правилах |
| `OWNER_ID` | Telegram ID владельца |
| `ALLOWED_CHAT_IDS` | Разрешённые группы через запятую |
| `ALLOWED_USER_IDS` | Пользователи с доступом к личке бота |

Владелец автоматически имеет доступ к личным сообщениям бота.

### 4. Запуск

```bash
sudo docker compose up -d --build
```

Просмотр логов:

```bash
sudo docker compose logs -f bot
```

### 5. Настройка Telegram

1. Создать бота через [@BotFather](https://t.me/BotFather).
2. Отключить Privacy Mode через `/setprivacy` → `Disable`.
3. Добавить ID группы в `ALLOWED_CHAT_IDS` или разрешить группу через `/allowgroup`.
4. Добавить бота в разрешённую группу.
5. Отправить `/start`.

Бот автоматически покидает группы, отсутствующие в белом списке.

## Команды бота

### Основные команды

| Команда | Описание |
|---|---|
| `/start` | Информация о боте и регистрация группы |
| `/stats` | Статистика за сегодня |
| `/yesterday` | Статистика за вчера |
| `/rules` | Правила челленджа |
| `/pravila` | Альтернативная команда правил |

### Управление доступом

Команды доступны только владельцу (`OWNER_ID`) в личном чате с ботом.

| Команда | Описание |
|---|---|
| `/myid` | Показать Telegram User ID |
| `/allowgroup <chat_id>` | Разрешить группу |
| `/denygroup <chat_id>` | Запретить группу |
| `/allowuser <user_id>` | Разрешить личные сообщения |
| `/denyuser <user_id>` | Запретить личные сообщения |
| `/access` | Показать текущие белые списки |

Изменения доступа сохраняются в SQLite и действуют без перезапуска бота.

## Правила челленджа

Текст правил хранится в отдельном файле `rules.txt`.

Поддерживаются переменные:

- `{DAILY_TARGET}` — базовая дневная норма.
- `{PENALTY_TARGET}` — штрафная дневная норма.
- `{REPORT_TIMEZONE}` — часовой пояс отчёта.

Пример `rules.txt`:

```text
🏋️ Правила челленджа

🎯 Ежедневная норма: {DAILY_TARGET} отжиманий.

🚨 Штрафная норма: {PENALTY_TARGET} отжиманий.

🕛 Отчёт каждый день в 00:00 ({REPORT_TIMEZONE}).
```

Правила перечитываются при каждом вызове `/rules`. Изменять текст можно без перезапуска, если файл доступен внутри контейнера.

## Принцип работы

1. Участник отправляет видеокружочек в разрешённую группу.
2. Бот анализирует видео и подсчитывает полные отжимания.
3. Если распознавание не удалось, бот запрашивает количество вручную.
4. Результат сохраняется в SQLite с привязкой к участнику и сообщению.
5. В 00:00 публикуется отчёт за прошедший день.
6. При невыполнении нормы на следующий день назначается штраф `DAILY_TARGET × 2 + 10`. Повторное невыполнение не увеличивает штраф.
7. После выполнения назначенной нормы участник возвращается к обычной дневной цели.

Результаты ручного ввода отмечаются ✍️.

### Debug-режим

Разрешённый пользователь может отправить кружочек боту в личные сообщения.

Бот покажет:

- Продолжительность и размер видео.
- Количество распознанных отжиманий.
- Количество обработанных кадров.
- Количество кадров с обнаруженной позой.
- Долю кадров с обнаруженной позой.
- Ошибку или причину невозможности распознавания, если она обнаружена.

Результаты debug-анализа не записываются в групповую статистику.

## Обновление с минимальным downtime

Сначала обновить исходный код:

```bash
git pull --ff-only
```

Собрать новый образ без остановки работающего бота:

```bash
sudo docker compose build bot
```

Пересоздать только контейнер бота:

```bash
sudo docker compose up -d --no-deps --force-recreate --no-build bot
```

Проверить состояние:

```bash
sudo docker compose ps
sudo docker compose logs -f --tail=100 bot
```

## Хранение данных

Статистика, результаты ручного ввода и изменения белых списков сохраняются в SQLite.

Для сохранения данных при пересоздании контейнера должен использоваться постоянный volume, соответствующий пути SQLite в конфигурации бота.

Одновременно должен работать только один экземпляр бота с Telegram long polling.
