# PushUp Tracker — Telegram-бот для отжиманий

Бот принимает видеокружочки (`video_note`) в Telegram-группе, автоматически подсчитывает отжимания с помощью MediaPipe и сохраняет результаты в SQLite.

Если видео не удалось обработать, участник указывает количество вручную. Такие результаты помечаются как требующие проверки.

Каждый день в 00:00 бот отправляет отчёт о выполнении дневной нормы. Если участник не выполнил норму, на следующий день она увеличивается в 3 раза.

## Сервер

Виртуальная машина (VPS):

- **OS:** Ubuntu 24.04 LTS
- **CPU:** 2 vCPU
- **RAM:** 2 GB
- **SSD:** 40 GB
- **Swap:** 1 GB

Приложение запускается через Docker Compose.

## Установка и запуск

### 1. Установка Docker

```bash
sudo apt update
sudo apt install -y docker.io docker-compose-v2 git
sudo systemctl enable --now docker
```

### 2. Клонирование проекта

```bash
git clone <REPOSITORY_URL>
cd push-up-tracker
```

### 3. Настройка окружения

```bash
cp .env.example .env
nano .env
```

Основные переменные:

```dotenv
BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
REPORT_TIMEZONE=Europe/Moscow
DAILY_TARGET=100
```

### 4. Запуск

```bash
sudo docker compose up -d --build
```

Просмотр логов:

```bash
sudo docker compose logs -f bot
```

### 5. Настройка Telegram

1. Создать бота через [@BotFather](https://t.me/BotFather).
2. Отключить Privacy Mode через `/setprivacy` → `Disable`.
3. Добавить бота в группу.
4. Отправить `/start` для регистрации группы.

## Команды бота

- `/start` — регистрация группы.
- `/stats` — статистика за сегодня.
- `/yesterday` — статистика за вчера.

## Обновление

```bash
git pull
sudo docker compose up -d --build
```

## Принцип работы

1. Участник отправляет кружочек с отжиманиями.
2. Бот автоматически подсчитывает повторения.
3. При ошибке распознавания запрашивает количество вручную.
4. Результат сохраняется в SQLite.
5. В 00:00 публикуется отчёт по участникам.
6. При невыполнении нормы на следующий день назначается `DAILY_TARGET × 2`. Повторное невыполнение не увеличивает множитель.
7. После выполнения назначенной нормы участник возвращается к обычной дневной цели.
