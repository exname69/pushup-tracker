# PushUp Tracker — Telegram бот для видеокружочков

Принимает `video_note` в группе, оценивает число **полных** отжиманий по ключевым точкам тела,
сохраняет результаты в SQLite и отправляет рейтинг **в 00:00 за прошедший день**.

## Запуск

1. Создайте бота в [@BotFather](https://t.me/BotFather) и получите токен.
2. Через `/setprivacy` → выберите бота → `Disable` разрешите видеть обычные сообщения в группе.
   После смены настройки удалите бота из группы и добавьте заново. Вместо этого можно назначить бота админом.
3. Создайте `.env`: `cp .env.example .env`; поставьте реальный `BOT_TOKEN` и часовой пояс
   `REPORT_TIMEZONE=Europe/Zurich` (например, `Europe/Moscow` для Москвы).
4. Запустите `docker compose up -d --build`.
5. Добавьте бота в Telegram-группу; напишите `/start` или отправьте кружочек.
6. Посмотреть логи: `docker compose logs -f bot`.

## Команды

- `/start` — зарегистрировать группу и показать инструкцию.
- `/stats` — статистика за текущий день в выбранном часовом поясе.
- `/yesterday` — статистика за вчера.

Каждый кружочек считается один раз благодаря `(chat_id, message_id)` в SQLite. Ролики
временно скачиваются для анализа, затем удаляются; в базе остаются имя отправителя,
Telegram user ID, количество отжиманий, дата и ID сообщения.

## Тесты счётчика и базы
Можно выполнить на хосте без ML-зависимостей:

```sh
python -m unittest discover -s tests -v
```

Для полного запуска на хосте необходим Python 3.11 и пакеты `requirements.txt`.
